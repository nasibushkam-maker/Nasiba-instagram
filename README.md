# Кўп функцияли Telegram Бот (Instagram Downloader + File Converter)

Ушбу бот 2 та асосий функцияни бажаради:
1. **Instagram видео юклаш**: Reels, Post, IGTV ҳаволаси юборилганда видео файлни юклаб беради.
2. **Универсал файл конвертери**: Ҳар қандай файл (Excel, Расм, Аудио, Видео, Ҳужжат) юборилганда уни керакли янги форматга ўгириб беради.

---

## 🔄 Қўллаб-қувватланадиган конвертациялар:

| Файл тури | Қабул қилинадиган форматлар | Ўзгартириш мумкин бўлган форматлар |
|---|---|---|
| **📊 Excel ва Жадваллар** | `.xlsx`, `.xls`, `.csv` | ➡️ **PDF ҳужжат (чиройли жадвал)**, **CSV (матнли)**, **HTML (веб саҳифа)**, **XLSX (Excel)** |
| **📑 Ҳужжатлар** | `.pdf`, `.docx`, `.txt` | ➡️ **DOCX (Word)**, **TXT (матн)**, **PNG расмлар**, **PDF** |
| **🖼 Расмлар** | `.jpg`, `.png`, `.webp`, `.bmp`, `.ico`, `.tiff` | ➡️ **PNG**, **JPG**, **WEBP**, **PDF**, **ICO**, **BMP** |
| **🎵 Аудио** | `.mp3`, `.wav`, `.ogg`, `.m4a`, `.aac`, `.flac` | ➡️ **MP3**, **WAV**, **OGG**, **M4A**, **AAC** |
| **🎬 Видео** | `.mp4`, `.mov`, `.avi`, `.mkv`, `.webm` | ➡️ **MP3 (Аудио олиш)**, **GIF (Анимация)**, **MP4**, **AVI**, **MKV** |

---

## 🚀 Ботни юргизиш
Папкадаги **`run_bot.bat`** файлини сичқонча билан икки марта боссангиз кифоя.
